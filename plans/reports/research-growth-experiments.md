## 1. Free Tier with Watermarked Delayed Signals

**Hypothesis** — Dropping a visible free tier converts 15-20% of active users to paid after 4 weeks; delays prevent arbitrage but still demonstrate edge.

**Experiment**
- Mirror existing Pro tier signals with 10 min delay + "COPIED FROM ALGO-TRADER" watermark on each signal line
- Gate: 50 free seats; cap at 20 API calls/hour
- Capture email on signup (already have auth infra)
- Track → paid conversion rate via NOWPayments webhook cohort

**Success Metric** — Free→paid conversion ≥12% in 30 days; ≥300 free signups

**Effort** — S (one Sprint: 1.5 days). Existing signal-publisher.ts already planned (migration 054); add delay layer + tier config flag.

**Expected Outcome** — $4.4k MRR at 25 paid users × $99 Pro tier. Timeline to revenue: 3-4 weeks.

**Risk** — Low. If leaks: tighten to 15 min delay. If cannibalization: reduce free quota to 10 calls/day.

## 2. Public Backtest Results Page (SEO)

**Hypothesis** — Backtest data is scarce in public; ranking for "strategy X backtest results" brings inbound organic traffic searching for trading strategy verification.

**Experiment**
- Build `/leaderboard` + `/backtests/[strategy-slug]` pages (already in plan)
- Include: Win rate, Sharpe, max drawdown, monthly returns table, 2-year equity curve chart (TradingView integration already exists)
- Add JSON-LD schema for "HowTo" + statistic data; canonical URLs
- Submit sitemap to Google; auto-ping on new backtest export

**Success Metric** — Top 10 Google ranking for ≥5 strategy-specific keywords in 90 days; ≥1k organic visits/month by day 60.

**Effort** — M (1 week). Pages already planned; add SEO meta + sitemap entry. Backtest data is generated by existing BacktestRunner.

**Expected Outcome** — Compound SEO value: 1k visitors/mo → ~40 signups/mo @ 4% conversion. Hardens trust for higher-tier sales.

**Risk** — Low. Strategy performance can be cherry-picked risk; mitigate with clear disclaimers + show full equity curve (drawdowns visible).

## 3. Reddit AMA in r/algotrading

**Hypothesis** — r/algotrading (1M+ members) actively discusses algo trading but few share real, auditable results; transparent AMA drives quality signups from engaged audience.

**Experiment**
- Post announcement + AMA date 5 days out; offer free strats access for top-voted questions
- AMA format: explain stack (CCXT+WS, DNA GRU, 52 strategies, backtest methodology) + answer questions
- Pin link to free tier + backtest results page in comments
- Moderator approval ahead of time (rule check: no direct linking to paid products in post body)

**Success Metric** — AMA post reaches top 5 in subreddit; ≥200 signups from referral link in 7 days post-AMA.

**Effort** — S (3 days: prep + post + 3-hour live session).

**Expected Outcome** — 200 signups × 10% paid = 20 new subs × $99 = $1.98k/mo recurring. Good signal quality (r/algotrading members are active traders, not tire-kickers).

**Risk** — Medium. Community pushback if perceived as "marketing disguised as questions." Mitigate: full transparency on methodology, admit trade-offs, avoid hype language.

## 4. Telegram Signal Group Seeding

**Hypothesis** — Engaged trading communities on Telegram convert at higher rate than cold Twitter traffic; real-time signal commentary builds trust and drives subscriptions.

**Experiment**
- Create @algo_trader_signals public group; post 3-4 curated signals/week from live Pro-tier feed (delayed 5 min)
- Embed NOWPayments subscription link in group pinned post + /subscribe bot command (Telegram bot already exists)
- Run 1-week "free trial" event: real-time signals for 7 days then convert
- Add group → landing page cross-links

**Success Metric** — 500 members in 30 days; ≥30 group-originated paid subscriptions.

**Effort** — M (1 week). Telegram bot infrastructure already exists (`src/platform/telegram/`). Need channel broadcasting + subscription deep link.

**Expected Outcome** — 30 subs × $99 = $2.97k/mo. Telegram users self-select; high intent. Low CAC (organic group growth).

**Risk** — Medium. Signal leakage if free trial signals are too real-time. Mitigate: watermark + manual signal selection (only high-conviction calls).

## 5. Weekly Market Recap with Embedded Signal Performance

**Hypothesis** — Traders consume weekly market recaps; embedding actual algo-trader signal win rates during the week drives habit differentiation and recurring engagement.

**Experiment**
- Every Sunday: auto-generate recap from signal journal + market data
- Layout: (a) market summary, (b) last week's signal performance table (win/loss/pnl), (c) this week's outlook + strategies to watch
- Publish as blog post + Twitter thread + Telegram newsletter
- Each recap contains one CTA: "See which strategy won 80%+ last week"

**Success Metric** — ≥1.5k email subscribers in 8 weeks; ≥15% weekly open rate; 50+ signal-feature page views per recap.

**Effort** — M (1 week setup; 2h/week ongoing). Signal journal already exists (24h rolling). Auto-generate from existing journal entries.

**Expected Outcome** — Compound trust asset. Long-tail SEO for "algo X weekly performance YYYY-MM-DD" queries. Induces habit; reduces churn by 20-30% in engaged segments.

**Risk** — Low. Bad weeks hurt; mitigate by showing average across rolling 4-week window (rollercoaster smoothing).

## 6. API Playground (Try Before Buy)

**Hypothesis** — Developers evaluating signal products install SDKs only after hands-on testing; live sandbox with 50 free API calls reduces friction and converts technical buyers faster.

**Experiment**
- Build `/api/playground` page: interactive API tester (Swagger-like, no auth required)
- Serve a small fixed set of iced/historical signals; no live feed
- "Get API key" CTA after 10 free calls → NOWPayments checkout
- Track: free call count, play→signup conversion, time-to-first-call

**Success Metric** — 500 sandbox sessions in 30 days; 8% free→paid conversion; ≥20 new API subscriptions.

**Effort** — L (2 weeks). Signals API routes already planned. Need sandbox endpoint + playground UI + auth tier for free tier.

**Expected Outcome** — 20 new API subs × $99 Pro = $1.98k/mo. API buyers have higher LTV ($200-500/mo typical). Developer-led growth compounds (SDK tutorials, GitHub stars).

**Risk** — Low-medium. Sandbox signals must not be old enough to be worthless; mitigate with 24h delay on sandbox data. Cost: low (no live feed until paid).

## 7. Twitter Live Signal Call Thread

**Hypothesis** — Live signal threads on X generate bursts of follows + signup clicks from traders scrolling #trading or #cryptotrading; authenticity ("real P&L screenshot") outperforms bot-tweet schedules.

**Experiment**
- @algo_trader account posts "live signal call" threads: strategy, entry, target, rationale (1-2 sentences of edge thesis)
- Include screenshot of real paper-trade P&L (paper trading engine already exists, $2,251 / 50 trades / 66.7% win rate)
- CTA to free tier link pinned; signal timestamps in UTC for verification
- Schedule 2x/week during high-volatility windows (NYC open, Asian gap)

**Success Metric** — 500 new followers in 30 days; ≥30 link-clicks per thread; 5% click-to-signup rate.

**Effort** — S (2 days setup; 30 min/thread ongoing). No new infra; reuse paper trading P&L reports.

**Expected Outcome** — 20 new paid subs × $29 Basic tier = $580/mo. Twitter as top-of-funnel for SEO signal-boost.

**Risk** — Low. Performance accountability: if calls go wrong, public accountability is actually a trust signal. Risk of being seen as "signals scam" — counter with full P&L history transparency (link to backtest page).

## 8. YouTube "How We Built This" Series

**Hypothesis** — Developer audience watches "real build" content; exposure from 10-episode build-in-public series brings sustained organic traffic + affiliate signal for other dev-first products.

**Experiment**
- 10-episode miniseries: architecture decisions, how we built arbitrage scanner (ep1), stealth order cloaking (ep2), DNA neural net pipeline (ep3), backtesting engine (ep4), marketplace billing (ep5), multi-tenant rate limiting (ep6), monitoring with Prometheus/Grafana (ep7), stress testing to 23k RPS (ep8), production deploy on Cloudflare Workers (ep9), what we'd do differently (ep10)

**Risk** — Medium. Opportunity cost (3 weeks of content vs shipping product features). Mitigate: batch record 2-3 episodes in single day, treat as sprint-long deliverable, not continuous weekly content.

## 9. Direct Outreach to Prop Firm Discord Communities

**Hypothesis** — Prop firm traders (e.g., FTMO, Topstep, Apex) actively search for signal verification tools; a free backtest page or trial delivers qualified leads from high-intent audience with disposable capital.

**Experiment**
- Identify key prop firm Discords + Telegram groups (15-20 communities)
- Offer free 7-day Pro trial + custom backtest report for their firm's strategies
- Create "Prop Firm Report" — PDF export showing how algo-trader would have performed on firm-style constraints (drawdown limits, profit targets)
- Personal DM to mods/community managers; request "partner" badge if engagement is good

**Success Metric** — Outreach to 20 communities; 5 partnerships accepted; ≥50 Pro trial activations; 20% trial→paid conversion.

**Effort** — M (2 weeks: prospect list, DM drafting, report automation). Requires manual outreach initially; can be templated.

**Expected Outcome** — Prop traders pay $99-299/mo without friction (this is their job). Prop firm referral: 50 users × $99 = $4.95k/mo. Marketplace for firm accounts (bulk pricing) up-sell path.

**Risk** — Medium-High. Discord/Telegram communities can be hostile to sales DMs. Mitigate: lead with value (free report), not pitch. Respect community rules; ask mods first for permission.

## 10. Cross-Promotion with Trading Tools

**Hypothesis** — TradingView indicator authors, Discord bot builders, and newsletter writers in crypto trading space have aligned audiences; mutual promotion/code-swap reaches buyers we can't access directly.

**Experiment**
- Identify 5-10 aligned tools: TradingView script authors (active in TV community), Telegram crypto alert bots, newsletter writers (e.g., @cryptowhalewatch), YouTube strategy reviewers
- Offer: (a) 30% affiliate revenue share for 6 months, (b) embeddable "powered by algo-trader backtest" widget for their site, (c) co-authored case study with both brands
- Prioritize tools with 1k-50k audience (mid-tier: easier to negotiate, engaged audience)

**Success Metric** — 3 partnership agreements signed in 30 days; ≥25 affiliate-referred signups in 60 days.

**Effort** — L (4 weeks: research, outreach, legal for rev-share, widget build). Widget: embeddable iframe showing live strategy performance.

**Expected Outcome** — 3 partners × 10 refs/ea. × $99 avg = $2.97k/mo. Low ongoing effort; compounds as partner audiences grow.

**Risk** — Low-medium. Rev-share disputes if tracking is unclear. Mitigate: unique referral codes + transparent dashboard in existing revenue analytics (already have affiliate API planned).

## Unresolved Questions

1. **Free tier signal delay** — What is the minimum delay that preserves signal edge while preventing copy-trade arbitrage? Unclear without running parallel backtest with varying delay windows.
2. **NOWPayments trial flow** — Does NOWPayments support recurring trial→paid billing natively, or does the existing migration 054 billing layer need custom trial-state handling?
3. **Influencer/referral fraud** — These experiments have no fraud prevention beyond NOWPayments attribution IDs. Should be scoped for Phase 2 (not blocking launch).
