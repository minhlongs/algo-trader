## 1. Value Propositions (Gia Tri Mang Lai)

### Business Layer

| Proposition | Description | Buyer Pain Point Solved |
|-------------|-------------|------------------------|
| **Single API + unified billing** | One integration for signals from multiple providers, one subscription | Fragmentation (#5) |
| **Trust infrastructure** | Hash-committed on-chain signals with independent verification | Trust (#1) |
| **Execution bridge** | Signal-to-execution automation reducing manual latency | Execution latency (#2) |
| **Standardized quality scores** | Objective performance metrics across all providers | Over-signaling (#4) |
| **Transparent pricing** | All-in subscription with no hidden costs | Hidden costs (#3) |

### Agentic Layer

| Proposition | Description |
|-------------|-------------|
| **MCP-native API** | AI agents discover and subscribe to signals via Model Context Protocol |
| **x402 pay-per-signal** | HTTP 402 micropayments (USDC on Base/Solana) for autonomous agent commerce |
| **Agent-discoverable signal registry** | Machine-readable catalog of available signal types, providers, and quality scores |
| **Self-learning ML fusion engine** | Combines multiple signals with EMA-based weight optimization |

### Governance Layer

| Proposition | Description |
|-------------|-------------|
| **Provenance verification chain** | Every signal hash-committed; track record immutable and auditable |
| **Burn-to-unlock dispute system** | Staking mechanism for challenging signal quality claims |
| **Provider bonding/slashing** | Economic disincentive for bad-faith signal provision |
| **Privacy-scoped tiers** | Zero-knowledge proofs for sensitive portfolio data |

## 11. Unresolved Questions (Cau Hoi Chua Giai Quyet)

1. **Provider seeding strategy:** Build internal signals first or recruit external providers at launch?
2. **Hardening sprint timeline implication:** Does the 2-week minimum push GTM past viable window?
3. **Securities law firewall:** Is the "no investment advice" disclaimer + tier filtering sufficient?
4. **x402 vs subscription primary model:** Which should be the primary GTM revenue driver?
5. **Single vs multi-chain:** Base-only for initial hash commits, or Solana/Ethereum from day one?
6. **Provider commission rate:** 10% or 15% platform commission on provider subscriptions?
7. **Data residency:** Do we need multi-region D1 for EU customers (GDPR)?
