## Classification Key

- `IMPLEMENTED_AND_VERIFIED` — Exists in source, matches PDF spec, and is covered by passing automated tests.
- `IMPLEMENTED_BUT_NOT_VALIDATED` — Implemented in source with unit tests, but requires licensed real-world data or live shadow/pilot observation to validate empirically.
- `PARTIAL` — Core implementation exists, but specific PDF invariants, thresholds, or wiring gaps remain (targeted for offline closure in POLY-G10).
- `NOT_IMPLEMENTED` — Missing or stubbed/mocked for live execution (requires implementation or hard fail-closed guard).
- `BLOCKED_EXTERNAL` — Gated on external license, legal opinion, Founder manual action, or third-party infrastructure.
- `NOT_APPLICABLE` — Explicitly excluded by PDF or outside POLY-G10 scope.

> **Epistemic Integrity Rule:** Offline fixtures, synthetic episodes, and unit drills are **never** classified as independently observed market data or validated alpha.
