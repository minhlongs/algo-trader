## Column Guide

| Column | Description |
|---|---|
| Date | ISO date posted (YYYY-MM-DD) |
| Channel | `twitter`, `hn`, `polymarket-bio`, `github` |
| Post URL | Direct link to the post/thread |
| Format | `weekly-thread`, `monthly-hn`, `pinned-bio`, `reply` |
| Views | Impressions at 48h mark (enter `-` if unavailable) |
| Replies | Reply count at 48h mark |
| Followers ∆ | Net follower change in 24h after post |
| Notes | Tone observation, engagement quality, template changes triggered |

## Review Schedule

Every 4 weeks: read last 4 rows, answer:
1. Which format got the most engagement?
2. Did honest bad-week posts outperform good-week posts?
3. Any template section consistently skipped by human editor? → remove it.

Results of each review → append a `## Review YYYY-WW` section below the log table.
