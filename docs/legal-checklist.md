# Legal Incorporation & Compliance Checklist

> Target entity: **Algo Trader Inc.** (Delaware C-Corp) — AI-driven algorithmic trading platform
> Status: Pre-incorporation planning

---

## 1. Incorporation

- [ ] **Entity type** — Delaware C-Corp (preferred for VC, cap table, equity grants)
- [ ] **Registered agent** — Select service (e.g. CSC, Registered Agents Inc.)
- [ ] **Certificate of Incorporation** — File with Delaware Division of Corporations
- [ ] **Authorized shares** — 10M common; class structure (Common + Preferred) for fundraising
- [ ] **Incorporator & initial directors** — Name incorporator; board seats for founders
- [ ] **EIN (IRS)** — Obtain Employer Identification Number
- [ ] **State registrations** — Foreign qualification in operating states (CA, NY if applicable)
- [ ] **Bank account** — Business bank account (Mercury, Brex, Chase)
- [ ] **Initial board resolutions** — Adopt bylaws, appoint officers, set fiscal year
- [ ] **Stock ledger / cap table** — Pulley, Carta, or AngelList for tracking

## 2. Securities Counsel

- [ ] **Engage securities counsel** — Law firm with FinTech / crypto / trading platform experience
- [ ] **Token / asset classification analysis** — Memo on whether signals, API access, or platform tokens are securities (Howey Test)
- [ ] **Subscription / API licensing structure** — Ensure revenue model does not constitute an unregistered securities offering
- [ ] **Accredited investor verification** — If offering profit-sharing, revenue share, or tokenized returns
- [ ] **Regulation D (506c) filing** — For private placement if raising capital
- [ ] **State blue sky filings** — Notice filings in states where investors reside
- [ ] **SEC no-action letter inquiry** — If platform has novel features (signal marketplace, copy-trading, automated execution)
- [ ] **CFTC classification** — Determine if algo signals cross into commodity advice (CCO designation if needed)
- [ ] **FinCEN registration** — MSB (Money Services Business) registration if handling fiat on/off ramp
- [ ] **OFAC / sanctions screening** — KYC/AML controls for API customers

## 3. Succession Protocol & Corporate Governance

- [ ] **Buy-sell agreement** — Founder departure, disability, death
- [ ] **Right of first refusal (ROFR)** — On transfer of founder shares
- [ ] **Drag-along / tag-along rights** — For future sale scenarios
- [ ] **Vesting schedule** — 4-year standard with 1-year cliff; acceleration clauses (single-trigger / double-trigger)
- [ ] **Board composition** — Founder seats, future investor seats, independent director
- [ ] **Key person insurance** — Life + disability on technical founders
- [ ] **Disaster recovery / business continuity plan** — Documented plan for trading system failure, data loss, exchange outage
- [ ] **IP assignment agreements** — All founders, employees, contractors sign IP assignment
- [ ] **Proprietary information / invention agreements** — Standard for all contributors
- [ ] **Data privacy policy** — Compliance with CCPA, GDPR (if EU users)
- [ ] **Terms of service** — API use, disclaimers, limitation of liability, no investment advice
- [ ] **Dispute resolution / arbitration clause** — Governing law (Delaware), venue

## 4. Intellectual Property

- [ ] **Trademark search** — "Algo Trader" / brand name availability (USPTO)
- [ ] **Trademark filing** — Class 9 (software), Class 36 (financial services), Class 42 (SaaS)
- [ ] **Copyright notices** — On source code, documentation, marketing materials
- [ ] **Trade secret protection** — Strategy algorithms, signal formulas, model weights (NDA + access control)
- [ ] **Domain registration** — Primary domain + defensive registrations
- [ ] **Open source compliance** — Audit dependencies for license compatibility (AGPL, BSL, etc.)

## 5. Operational Compliance

- [ ] **Data retention policy** — Trade data, user data, API logs
- [ ] **SOC 2 Type II** — Engage auditor if enterprise customers require it
- [ ] **ISO 27001** — If targeting financial institution clients
- [ ] **Insurance** — D&O, E&O, cyber liability, general liability
- [ ] **GDPR / Schrems II** — Data transfer mechanism if EU users
- [ ] **CCPA** — California privacy disclosures
- [ ] **FDIC / broker-dealer determination** — Memo confirming platform is not a broker-dealer
