Chapter 3: Running the Market-Maker Bot

Follow these procedures to initialize the market-making engine. Precision in configuration is critical for liquidity provision and risk mitigation.

01

Environment Check

Before ignition, verify that all cryptographic keys and exchange endpoints are correctly mapped in your local environment file. 

# Check environment existence
ls -la | grep ".env"

# Verify mandatory keys are populated
cat .env | grep -E "API_KEY|SECRET|ENV_MODE"
info

Ensure ENV_MODE is set to PRODUCTION for live trading or STAGING for sandboxed testing.

02

Initializing the Core

Launch the bot using the designated startup script. The --mode=aggressive flag ensures the bot stays within the top 3 depth levels of the order book. 

npm run start -- --mode=aggressive
03

Monitoring Logs

Once initialized, the CLI will stream real-time telemetry. Operators must monitor for the following specific signals:

sync_alt Spread Adjustments

Look for [SPD_ADJ] entries indicating the bot is recalculating mid-price based on volatility.

shopping_cart Order Fills

Successful trades appear as [FILL_OK]. Verify that inventory levels remain within balanced limits.
